# P1: Hidden Patch — Train the Noise Localizer

## Current objective and scope

Implement and train a small U-Net that localizes **any annotated added noise** in a complete 64 × 64 image: both adversarial patches and decoys. Convert its output into a small set of candidate rectangles, evaluate proposal coverage independently, and then connect it to the existing residual + label-free ResNet classifier.

Keep the two stages explicit:

| Stage | Supervision | Output |
| --- | --- | --- |
| Noise localizer | Attack pixels and decoy pixels are positive; unmarked pixels are background | A dense noise-probability map and candidate rectangles |
| Existing attack classifier | Attack versus non-attack regions | A continuous attack score for each candidate |

The primary deliverable is a trained, evaluated localizer. A grid-only run or reuse of the old residual classifier does not complete this milestone. Preserve existing code, checkpoints, split manifests, and completed experiment outputs.

Do not train an IoU regressor, generate weaker attacks, attempt clean-image recovery, or submit to the competition portal in this milestone. Weaker-attack augmentation remains a future idea; test difficulty is not known to mean lower epsilon. Do not rerun the completed robustness/background/ablation suite unless a concrete implementation change requires it.

## Evidence motivating this change

The earlier user-supplied annotated-box results were:

| Model | ROC-AUC | Average precision | Within-image ranking |
| --- | --- | --- | --- |
| Residual logistic | 0.675 | 0.580 | 60.7% |
| Boosting | 0.666 | 0.628 | 63.2% |
| Small CNN | 0.690 | 0.599 | 62.4% |
| Residual + label-free ResNet | 0.969 | 0.970 | 96.3% |

These are reference measurements, not results independently reproduced by the next implementation. Annotated-box ranking does not measure full-image localization or absence detection.

The subsequent report evaluated a small holdout of 40 images: 32 attacked, four decoy-only, and four clean.

| Proposal stage | Mean best available attack IoU | Attack recall at IoU >= 0.5 |
| --- | --- | --- |
| Full grid, 265 rectangles | 0.6924 | 100% |
| Old shortlist, at most 16 rectangles | 0.2998 | 25% |

The combined classifier selected boxes with mean attack IoU 0.2201; the final image score was 0.2511. These small-sample results are diagnostic, not a reliable full-test estimate.

The old shortlist reused logistic regression on 44 residual features trained on **annotated attacks versus annotated decoys**. It had no noise-versus-background localization objective. Both deployment-compatible scorers used the 3,200-image fitting partition. This implementation choice discarded useful candidates on 24 of 32 attacked holdout images.

Retain that method only as a clearly named historical baseline. Do not reuse its scores to filter the U-Net's candidates. Its failure does not establish whether attack and decoy noise can be localized from images.

The report also found selected IoU 0.6237 when exact boxes and imperfect variants were available together, despite an available IoU of 1.0. Boundary ranking is a separate remaining problem. Measure it, but prioritize recovering useful proposals first.

## Data contract

The extracted dataset contains `train/images/<id>.png` and `train_labels.csv`. Images are 64 × 64 RGB. Read pixels as floats in [0, 1], without resizing or recompressing them. Original clean counterparts are not provided: filtering residuals contain natural texture and JPEG effects, not just the true perturbation.

CSV columns:

```text
id,split,usage,tier,x_min,y_min,x_max,y_max,comment
```

Boxes use exclusive upper bounds: `image[y_min:y_max, x_min:x_max]`. The box `(0,0,0,0)` means no adversarial patch; it does not imply that there are no decoys. Valid patches may touch any image boundary.

Reuse the proper CSV/comment parser. Extract attack type, epsilon, true class ID, JPEG quality, and every decoy's type, box, and available norm parameters. Keep nominal epsilon, L2, and reported Linf separate; missing values are not zero. Support clean and decoy-only images. Report unsupported comments and count mismatches rather than silently dropping annotations.

Keep these parser fixtures:

```csv
id,split,usage,tier,x_min,y_min,x_max,y_max,comment
498461a86049,train,,standard,16,36,31,64,"ADV mifgsm_linf_u eps=20/255 true=n02481823; decoys: 1 rademacher eps=3/255 at [34,34,59,48]; jpeg=95"
64863c659e5c,train,,standard,0,33,16,54,"ADV mifgsm_linf_u eps=20/255 true=n04596742; decoys: 2 uniform eps=6/255 at [44,38,63,61], gaussian l2=0.33 linf=3.9/255 at [20,35,39,56]; jpeg=92"
```

Annotation fields supervise training and evaluation only. True semantic class, attack family, strength, JPEG quality, group membership, and candidate origin must not become inference inputs.

## Build the union-mask dataset

For each image, initialize a 64 × 64 zero mask. Fill the true attack rectangle, if present, and every decoy rectangle with ones. Preserve individual rectangles and their types separately for evaluation.

- Attacked image: attack and all decoys are positive.
- Decoy-only image: decoys are positive for localization, although its final competition answer must be NONE.
- Clean image: the entire mask is zero.

Train on complete images, including their unmarked background. Never use attack-versus-decoy labels as the localizer's binary target. Never omit clean images.

Build input channels from RGB plus the two existing signed RGB residual maps: nine channels total. Compute filtering on the full image before any regional operation. Reuse the implemented filter definitions and save their parameters; do not silently replace them. Any channel scaling must be fixed or fitted on fitting images only and saved with the checkpoint.

Begin without image augmentation. Resizing, recompression, additional noise, strong color transforms, and patch-level normalization could alter the signal. Do not create synthetic attacks or assume a smoothed image is a clean training target.

## Minimal U-Net and training

Use a small U-Net trained from scratch at native resolution:

- Encoder widths 16, 32, 64, 128 with three downsampling steps: 64 -> 32 -> 16 -> 8.
- Padded 3 × 3 convolutions, skip connections, and an upsampling decoder returning 64 × 64.
- One output logit per pixel; apply sigmoid for inference.
- No supplied ResNet features, logits, gradients, or interventions in the localizer.

Use BCEWithLogits plus soft Dice loss, initially with equal coefficients. Include clean images in BCE and handle empty masks with a stable, finite Dice definition. Do not threshold predictions or extract boxes inside the training loss; hard box IoU is not the segmentation training objective.

Start with AdamW, learning rate 1e-3, weight decay 1e-4, batch size 32, at most 30 epochs, and early-stopping patience five. These are initial experimental settings, not validated optimal values. Use seed 42, CUDA when available, and a CPU fallback; document necessary batch-size changes.

Select the checkpoint using calibration **attack proposal recall at IoU >= 0.5 and K=16**, with mean best attack IoU as a tie-breaker. Also record union-mask loss/IoU and separate decoy recall. Do not select checkpoints solely by a pixel metric dominated by background or easy decoys.

Do not optimize or retrain the second-stage classifier during this first localizer comparison.

## Deterministic mask-to-box decoder

Keep the first decoder simple and directly comparable to the existing experiment. Reuse the published-prior grid: sizes (14,28), (28,14), (16,24), (24,16), (20,20), (24,24), stride eight, including all boundary placements. Reuse the existing implementation and verify its reported 265 unique rectangles per image.

For each rectangle, compute the **mean U-Net noise probability inside it**. Rank by this score, use deterministic tie-breaking, and apply greedy geometric suppression of boxes with IoU > 0.7 against an already retained box. Retain at most K=16. Save candidate counts before and after suppression. This scoring and suppression rule is a starting decoder, not a claim of optimal geometry.

Use only the image and trained localizer at inference. Do not seed, enlarge, filter, or reorder candidates with annotations, true class, residual attack-classifier scores, or ResNet responses. A clean image may still produce candidates; the final rejection decision belongs to the complete pipeline.

The grid is only a geometric decoder of a learned map. Its unchanged rectangle bank makes it possible to test whether the new model retains good windows that the old shortlist discarded. It still limits achievable boundary precision. Do not describe it as learned box regression.

Evaluate K=16 as the primary budget. Small calibration comparisons at K=32 and K=64 are allowed if coverage remains poor; record cost and recalibrate the final rejection threshold separately for each budget. Do not tune an extensive decoder search. Component-derived boxes or local boundary refinement are follow-up options if the fixed-grid coverage ceiling becomes the main limitation.

## Evaluate localization before the classifier

For attacked images, compute the maximum IoU between the attack box and any retained candidate; use zero for an empty candidate set. Report:

- Attack recall@K at IoU thresholds 0.3, 0.5, and 0.7.
- Mean best available attack IoU.
- The same coverage metrics on the complete grid before selection.
- Candidate count and inference time, including map generation and decoding.

Report decoy recall separately over individual decoy boxes, with counts, rather than pooling it with attack recall. Keep the attacked-image denominator explicit. Break down attack coverage by attack family and available strength/JPEG strata where counts permit. Small groups support descriptive comparisons only.

Compare the old residual shortlist and the U-Net shortlist on identical image IDs, rectangle bank, K, and evaluation code. Do not attribute changes from candidate-budget or decoder differences solely to the network. Save union-mask predictions and overlays containing true boxes, proposed boxes, and missed attacks.

A high union-mask IoU or good decoy recall is insufficient if attack recall remains poor. The main question is whether stage two receives a useful attack rectangle.

## Preserve and connect the existing attack scorer

Keep the recovered frozen reference checkpoint and identify it as recovered rather than the missing original checkpoint. It was fitted on all 4,000 original training images, including the later calibration partition, so it remains diagnostic only.

Use the existing calibration-compatible combined scorer fitted on the 3,200-image fitting partition for the main pipeline. Preserve its 44 residual features and six label-free ResNet intervention features. Keep feature allowlists explicit; coordinates select pixels but annotation-derived fields, candidate origin, and actual IoU are not predictors.

Compute smoothing on the full image. For each candidate independently, start from the original image and replace only that rectangle with the corresponding smoothed pixels. Run the supplied frozen ResNet on the full 64 × 64 modified image with its actual input preprocessing. Hold the original predicted class fixed when measuring changes in its margin or probability. Never smooth candidates cumulatively.

Use the classifier's continuous score, not a hard binary prediction, to rank candidates. Keep the classifier fixed during the first U-Net evaluation. Cache original logits and smoothing buffers, batch modified-image forwards, and recompute candidate features when coordinates change.

Report selected attack IoU before rejection alongside the localizer's best available attack IoU. This separates missing good proposals from failure to choose among existing ones. Existing binary confidence is not an estimate of box IoU.

If later evidence justifies adapting the classifier to background or imperfect proposals, treat it as a separate experiment. Obtain training proposals out of fold by source image where practical, recompute targets from actual overlap, and retain decoys as important negatives. Do not silently add IoU regression or claim that a median selected/true area ratio alone diagnoses all boundary errors.

## Splits, calibration, and final scoring

Reuse the persisted 3,200 fitting / 800 calibration / 1,000 holdout image assignments. Inspect the saved manifests rather than generating a new split. All candidates, masks, and derivatives from one image remain together. Fit the localizer and learned preprocessing on fitting images only.

Use calibration images for checkpoint/decoder selection and the final rejection threshold. Do not use the holdout to select settings. The earlier 40-image holdout subset has already been inspected; retain its assignments and disclose this prior diagnostic use. Evaluate the chosen final configuration on the full held-out population when available, with counts and no subsequent tuning on that result.

A smoke run is an implementation check, not the final experiment. Clearly separate selected diagnostic image counts from actual model-fitting counts; the previous phase table's 40 images did not mean that the old logistic models were fitted on only 40 images.

For each budget, calibrate rejection after the complete candidate-generation, ranking, and maximum-selection procedure. A threshold of 0.5 is not automatically appropriate. Changing the candidate generator changes the distribution of maximum scores.

Return exactly one integer rectangle or (0,0,0,0). On attacked images, the official score is IoU with the true attack box, with zero for abstention. On no-attack images, it is one only for NONE. Average over images. Report the all-zero baseline on the actual population, group counts/scores, and image-level false-positive rates separately for clean and decoy-only images.

Do not use test images, test metadata, or leaderboard feedback for training or setting selection. Test images may be read **only for inference** by `localizer-submit` (see the addendum); they never enter fitting, calibration, thresholds, checkpoint or decoder selection, or any tuning. Keep diagnostic known-box metrics separate from full-image results.

uv run python -m src --data-dir data --output-dir outputs/next --baseline-dir outputs/full --experiment resnet

### Positional shortcut and dihedral augmentation

In the fitting data every patch and decoy has `y_min >= 32`. The first localizer (`outputs/unet`, no augmentation) scores 0.875 attack recall@16/IoU 0.5 on the holdout, but a fixed bottom-half mean mask built from fitting annotations alone scores 0.764, and the localizer scores **0.000** when holdout images and boxes are flipped vertically. Test images are not bottom-heavy in residual energy (bottom/top ratio 1.021, 95% CI 1.010-1.031, versus 1.076 for noisy training images), so the original holdout number overstates expected test performance.

`--augment` trains with an independent random dihedral transform per sample (flips, transposes, 90-degree rotations) applied to the nine input channels and the mask. This is equivalent to transforming the image first because the filters are isotropic with reflect padding; `noise_model.self_test` verifies it, and verifies that transformed boxes match transformed masks in all eight orientations. With `--augment`, checkpoint selection uses calibration attack recall and mean best IoU averaged over all eight orientations. Without the flag, behavior and config files are unchanged. Use a new `--output-dir` for augmented runs:

```sh
uv run python -m src --data-dir data --output-dir outputs/unet_aug --localizer-source outputs/localization \
    --experiment localizer-all --augment
```

Recorded results on the 1,000-image holdout (798 attacked images, K=16):

| Model | Recall@IoU .5, original / vflip / transpose | Official score | Chosen-box IoU |
| --- | --- | --- | --- |
| Full grid (ceiling) | 1.000 | - | 0.731 best available |
| Historical residual shortlist | 0.197 | - | - |
| `outputs/unet` (no augmentation) | 0.875 / 0.000 / 0.261 | 0.487 | 0.468 |
| `outputs/unet_aug` (`--augment`) | 0.431 / 0.457 / 0.436 | 0.353 | 0.305 |

The all-zero baseline is 0.202. The augmented model stopped at epoch 3 of 8 and is probably undertrained (union-mask IoU at 0.5 is near zero, so its probabilities are underconfident, although ranking by mean probability still works). Treat 0.353 as the more realistic expectation if test patches are not confined to the bottom half; this is an inference, not a measurement on test labels.

### Devices

`--device` accepts `auto`, `cpu`, `cuda`, `mps`. `auto` prefers CUDA, then MPS, then CPU. `torch.use_deterministic_algorithms(True)` stays on for every device. MPS ResNet inference measured about 7.5 times faster than CPU with logits within 3e-5. The candidate cache signature includes the device, so a cache built on CPU (`outputs/localization/cache`) refuses to load on MPS; rerun on `--device cpu` to resume, or use a fresh cache directory.

### Submission file generation

`--experiment localizer-submit` runs the saved deployment on the test images and writes the competition CSV:

```sh
uv run python -m src --data-dir data --output-dir outputs/unet_aug --localizer-source outputs/localization \
    --experiment localizer-submit [--submission PATH] [--limit N] [--device auto]
```

- Reads `data/test_ids.csv` and `data/test/images/<id>.png`; requires native 64 x 64 RGB.
- Uses only the image and frozen components: the localizer in `--output-dir`, the `fit_combined` scorer from `--localizer-source`, and the calibration-selected threshold in `deployment.json`. It verifies the localizer, scorer, preprocessing, and decoder hashes recorded at calibration and refuses to run if any changed. K is fixed at 16.
- For each image: decode up to 16 proposals, score each with the scorer, take the maximum, and output that box if its score reaches the threshold, otherwise `(0,0,0,0)`. Every row holds exactly one integer rectangle with exclusive upper bounds, or all zeros.
- Writes `<output-dir>/submission.csv` with columns `id,x_min,y_min,x_max,y_max`, one row per id in `test_ids.csv` order, and validates ids and columns against `data/sample_submission.csv` when present. Also writes `submission_scores.csv` (adds `max_score`, `candidates`) and `submission_metadata.json` (threshold, hashes, device, abstention count and rate, forward counts, runtime).
- `--limit N` is a smoke test: it writes `submission_smoke.csv` and metadata marked `complete: false`. Do not submit it.
- Test features are cached in `<output-dir>/submission_cache`, separate from the fitting/calibration cache.
- Test images are used for inference only. The threshold was calibrated on calibration images before any test image was read. No leaderboard feedback may be used to change the checkpoint, threshold, or decoder; uploading the CSV to the portal remains a manual step outside this repository.

Smoke check (2026-11-03, `outputs/unet_aug`, MPS): 20 test images in 3.5 seconds, 6 abstentions. The full 5,000-image submission has not been generated yet; running it takes roughly 15 minutes on MPS.
